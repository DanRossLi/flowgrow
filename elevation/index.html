Elevation maps

The same island and the same tiles as the usual game, with heights (LOU-310): a river can go level or down a step, never up, and a step down is a waterfall. Three ways the land can be shaped. Each map has its own saved run and best score.

FoothillsThe land falls away from the source in rings, with some bumps. RidgesRidges run out from the source, with lower land between them. TerracesBroad flat tiers fall away in one direction, with sharp steps between.
